К главной подгруппе III группы (13-я группа по классификации ИЮПАК) относятся бор ($\text{B}$), алюминий ($\text{Al}$), галлий ($\text{Ga}$), индий ($\text{In}$) и таллий ($\text{Tl}$).

1. Общая характеристика элементов

  • Общая электронная формула валентного слоя: $ns^2 np^1$
  • Характерные степени окисления: $+3$ (для $\text{B}$ и $\text{Al}$), $+1$ и $+3$ (для $\text{Ga}$, $\text{In}$, $\text{Tl}$). С ростом атомного номера устойчивость степени окисления $+1$ возрастает (проявление эффекта инертной $s$-пары), а $+3$ — уменьшается.
  • Изменение свойств в группе сверху вниз: металлические свойства усиливаются, радиус атомов увеличивается, электроотрицательность в целом уменьшается. Бор — неметалл (полупроводник), остальные элементы — металлы.

2. Бор ($\text{B}$) и его соединения

2.1. Химические свойства бора

  • Взаимодействие с неметаллами при нагревании:
    $4\text{B} + 3\text{O}_2 \xrightarrow{t} 2\text{B}_2\text{O}_3$
    $2\text{B} + 3\text{Cl}_2 \xrightarrow{t} 2\text{BCl}_3$
    $2\text{B} + \text{N}_2 \xrightarrow{t} 2\text{BN}$ (нитрид бора)
  • Взаимодействие с металлами (образование боридов):
    $3\text{Mg} + 2\text{B} \xrightarrow{t} \text{Mg}_3\text{B}_2$
  • Взаимодействие с кислотами-окислителями:
    $\text{B} + 3\text{HNO}_3 \text{ (конц.)} \xrightarrow{t} \text{H}_3\text{BO}_3 + 3\text{NO}_2\uparrow$
  • Взаимодействие со щелочными расплавами в присутствии окислителей:
    $2\text{B} + 6\text{KOH} + 3\text{KNO}_3 \xrightarrow{t} 2\text{K}_3\text{BO}_3 + 3\text{KNO}_2 + 3\text{H}_2\text{O}$

2.2. Оксид и кислота бора

  • Оксид бора ($\text{B}_2\text{O}_3$) — кислотный оксид.
    $\text{B}_2\text{O}_3 + 3\text{H}_2\text{O} \rightarrow 2\text{H}_3\text{BO}_3$ (борная кислота)
  • Ортоборная кислота ($\text{H}_3\text{BO}_3$) — слабая одноосновная кислота Льюиса (присоединяет гидроксид-ион):
    $\text{H}_3\text{BO}_3 + 2\text{H}_2\text{O} \rightleftharpoons [\text{B}(\text{OH})_4]^- + \text{H}_3\text{O}^+$
  • Разложение борной кислоты при нагревании:
    $\text{H}_3\text{BO}_3 \xrightarrow{t} \text{HBO}_2 + \text{H}_2\text{O}$ (метаборная кислота)
    $4\text{HBO}_2 \xrightarrow{t} \text{H}_2\text{B}_4\text{O}_7 + \text{H}_2\text{O}$ (тетраборная кислота)
    $\text{H}_2\text{B}_4\text{O}_7 \xrightarrow{t} 2\text{B}_2\text{O}_3 + \text{H}_2\text{O}$
  • Бораны (водородородные соединения бора, например диборан $\text{B}_2\text{H}_6$):
    $\text{B}_2\text{H}_6 + 6\text{H}_2\text{O} \rightarrow 2\text{H}_3\text{BO}_3 + 6\text{H}_2\uparrow$

3. Алюминий ($\text{Al}$) и его соединения

3.1. Химические свойства алюминия

Алюминий — амфотерный металл, легко пассивируется концентрированными $\text{HNO}_3$ и $\text{H}_2\text{SO}_4$ на холоду.

  • Реакция с простыми веществами:
    $4\text{Al} + 3\text{O}_2 \rightarrow 2\text{Al}_2\text{O}_3$
    $2\text{Al} + 3\text{Hal}_2 \rightarrow 2\text{AlHal}_3$ ($\text{Hal} = \text{F, Cl, Br, I}$)
    $4\text{Al} + 3\text{C} \xrightarrow{t} \text{Al}_4\text{C}_3$ (карбид алюминия)
    $2\text{Al} + \text{N}_2 \xrightarrow{t} 2\text{AlN}$ (нитрид алюминия)
    $2\text{Al} + 3\text{S} \xrightarrow{t} \text{Al}_2\text{S}_3$ (сульфид алюминия, полностью гидролизуется водой)
  • Алюминотермия (восстановление металлов из их оксидов):
    $8\text{Al} + 3\text{Fe}_3\text{O}_4 \xrightarrow{t} 4\text{Al}_2\text{O}_3 + 9\text{Fe}$
    $2\text{Al} + \text{Cr}_2\text{O}_3 \xrightarrow{t} \text{Al}_2\text{O}_3 + 2\text{Cr}$
  • Взаимодействие с водой (после удаления оксидной плёнки):
    $2\text{Al} + 6\text{H}_2\text{O} \rightarrow 2\text{Al}(\text{OH})_3\downarrow + 3\text{H}_2\uparrow$
  • Взаимодействие с кислотами-неокислителями:
    $2\text{Al} + 6\text{HCl} \rightarrow 2\text{AlCl}_3 + 3\text{H}_2\uparrow$
  • Взаимодействие со щелочами:
    В растворе: $2\text{Al} + 2\text{NaOH} + 6\text{H}_2\text{O} \rightarrow 2\text{Na}[\text{Al}(\text{OH})_4] + 3\text{H}_2\uparrow$
    При спекании: $2\text{Al} + 2\text{NaOH} \xrightarrow{t} 2\text{NaAlO}_2 + \text{H}_2\uparrow$

3.2. Амфотерность оксида и гидроксида алюминия

  • Оксид алюминия ($\text{Al}_2\text{O}_3$):
    С кислотами: $\text{Al}_2\text{O}_3 + 6\text{HCl} \rightarrow 2\text{AlCl}_3 + 3\text{H}_2\text{O}$
    С растворами щелочей: $\text{Al}_2\text{O}_3 + 2\text{NaOH} + 3\text{H}_2\text{O} \rightarrow 2\text{Na}[\text{Al}(\text{OH})_4]$
    При спекании со щелочами/карбонатами:
    $\text{Al}_2\text{O}_3 + 2\text{NaOH} \xrightarrow{t} 2\text{NaAlO}_2 + \text{H}_2\text{O}$
    $\text{Al}_2\text{O}_3 + \text{Na}_2\text{CO}_3 \xrightarrow{t} 2\text{NaAlO}_2 + \text{CO}_2\uparrow$
  • Гидроксид алюминия ($\text{Al}(\text{OH})_3$):
    С кислотами: $\text{Al}(\text{OH})_3 + 3\text{HNO}_3 \rightarrow \text{Al}(\text{NO}_3)_3 + 3\text{H}_2\text{O}$
    С раствором щелочи: $\text{Al}(\text{OH})_3 + \text{NaOH} \rightarrow \text{Na}[\text{Al}(\text{OH})_4]$
    Термическое разложение: $2\text{Al}(\text{OH})_3 \xrightarrow{t} \text{Al}_2\text{O}_3 + 3\text{H}_2\text{O}$

3.3. Важнейшие реакции солей алюминия

  • Полный необратимый гидролиз солей слабых кислот (сульфидов, карбонатов, сульфитов):
    $\text{Al}_2\text{S}_3 + 6\text{H}_2\text{O} \rightarrow 2\text{Al}(\text{OH})_3\downarrow + 3\text{H}_2\text{S}\uparrow$
    $2\text{AlCl}_3 + 3\text{Na}_2\text{CO}_3 + 3\text{H}_2\text{O} \rightarrow 2\text{Al}(\text{OH})_3\downarrow + 3\text{CO}_2\uparrow + 6\text{NaCl}$
  • Разрушение комплексных тетрагидроксоалюминатов:
    Избытком сильной кислоты: $\text{Na}[\text{Al}(\text{OH})_4] + 4\text{HCl} \rightarrow \text{NaCl} + \text{AlCl}_3 + 4\text{H}_2\text{O}$
    Недостатком сильной кислоты: $\text{Na}[\text{Al}(\text{OH})_4] + \text{HCl} \rightarrow \text{NaCl} + \text{Al}(\text{OH})_3\downarrow + \text{H}_2\text{O}$
    Пропусканием углекислого газа: $\text{Na}[\text{Al}(\text{OH})_4] + \text{CO}_2 \rightarrow \text{NaHCO}_3 + \text{Al}(\text{OH})_3\downarrow$
    Пропусканием сероводорода: $\text{Na}[\text{Al}(\text{OH})_4] + \text{H}_2\text{S} \rightarrow \text{NaHS} + \text{Al}(\text{OH})_3\downarrow + \text{H}_2\text{O}$

4. Подгруппа галлия, индия и таллия ($\text{Ga}$, $\text{In}$, $\text{Tl}$)

  • Галлий и индий по химическим свойствам аналогичны алюминию (проявляют амфотерность):
    $2\text{Ga} + 6\text{NaOH} + 6\text{H}_2\text{O} \rightarrow 2\text{Na}_3[\text{Ga}(\text{OH})_6] + 3\text{H}_2\uparrow$
  • Таллий в степени окисления $+1$ напоминает металлы щелочной подгруппы и серебро:
    $\text{TlOH}$ — сильное растворимое основание (щёлочь).
    $\text{TlCl}$ — малорастворимый белый осадок (аналог $\text{AgCl}$).
  • Переход между степенями окисления $+3$ и $+1$ для таллия:
    $\text{TlCl}_3 \xrightarrow{t} \text{TlCl} + \text{Cl}_2$ (соединения $\text{Tl(III)}$ — сильные окислители)

5. Качественные реакции

  • Качественная реакция на ион $\text{Al}^{3+}$: образование белого студенистого осадка $\text{Al}(\text{OH})_3$, растворимого как в избытке щелочи, так и в сильных кислотах.
  • Качественная реакция на борные кислоты и бораты: образование триэтилбората, горящего зелёным пламенем:
    $\text{H}_3\text{BO}_3 + 3\text{C}_2\text{H}_5\text{OH} \xrightarrow{\text{H}_2\text{SO}_4 \text{ (конц.)}} \text{B}(\text{OC}_2\text{H}_5)_3 + 3\text{H}_2\text{O}$
