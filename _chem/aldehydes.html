1. Общие сведения и строение карбонильной группы

Альдегиды и кетоны — это органические соединения, содержащие карбонильную группу $\ce{>C=O}$.

  • Альдегиды: Карбонильная группа связана с атомом водорода и органическим радикалом (или двумя атомами водорода в случае формальдегида). Общая формула: $\ce{R-CHO}$.
  • Кетоны: Карбонильная группа связана с двумя углеводородными радикалами. Общая формула: $\ce{R1-CO-R2}$.

Электронное строение: Атом углерода карбонильной группы находится в $sp^2$-гибридизации. Связь $\ce{C=O}$ сильно поляризована из-за большей электроотрицательности кислорода: $\ce{\overset{\delta+}{C}=\overset{\delta-}{O}}$. Это определяет высокую реакционную способность в реакциях нуклеофильного присоединения ($\text{A}_\text{N}$).

2. Способы получения (лабораторные и промышленные)

Промышленные методы и современные технологии

  1. Каталитическое гидратирование алкинов (Реакция Кучерова):
    Получение ацетальдегида из ацетилена в присутствии солей ртути(II) в кислой среде:
    $\ce{HC\equiv CH + H2O ->[Hg^{2+}, H^+][H2SO4] CH3CHO}$
    Для гомологов ацетилена образуются кетоны:
    $\ce{CH3-C\equiv CH + H2O ->[Hg^{2+}, H^+] CH3-CO-CH3}$
  2. Окисление алкенов (Wacker-процесс / Вэкер-процесс):
    Современный промышленный метод получения ацетальдегида прямой окислительной гидратацией этилена кислородом в присутствии $\ce{PdCl2}$ и $\ce{CuCl2}$:
    $\ce{2CH2=CH2 + O2 ->[PdCl2, CuCl2] 2CH3CHO}$
  3. Кумольный способ (синтез ацетона и фенола):
    Окисление изопропилбензола (кумола) кислородом воздуха с последующим кислотным расщеплением гидропероксида кумола:
    $\ce{C6H5-CH(CH3)2 + O2 -> C6H5-C(CH3)2-O-O-H ->[H2SO4] C6H5OH + CH3-CO-CH3}$
  4. Дегидрирование спиртов (в промышленности):
    Пропускание паров спирта над медным или серебряным катализатором при $300\text{--}500^\circ\text{C}$:
    $\ce{R-CH2OH ->[Cu, \Delta] R-CHO + H2\uparrow}$ (из первичных спиртов)
    $\ce{R1-CH(OH)-R2 ->[Cu, \Delta] R1-CO-R2 + H2\uparrow}$ (из вторичных спиртов)
  5. Гидролиз геминальных дигалогенопроизводных:
    $\ce{R-CHCl2 + 2NaOH -> R-CHO + 2NaCl + H2O}$
    $\ce{R1-CCl2-R2 + 2NaOH -> R1-CO-R2 + 2NaCl + H2O}$
  6. Оксосинтез (гидроформилирование алкенов):
    Взаимодействие алкенов с синтез-газом ($\ce{CO + H2}$) на кобальтовых или родиевых катализаторах:
    $\ce{R-CH=CH2 + CO + H2 ->[Co / Rh, p, T] R-CH2-CH2-CHO}$

Лабораторные методы селективного окисления

  • Мягкое окисление первичных спиртов реагентом PCC (пиридиний хлорхромат) или PDC: позволяет остановить окисление на стадии альдегида, не доводя до карбоновой кислоты:
    $\ce{R-CH2OH ->[PCC][CH2Cl2] R-CHO}$
  • Окисление по Сверну (Swern oxidation): использование оксалилхлорида $\ce{(COCl)2}$, ДМСО и триэтиламина для мягкого превращения спиртов в альдегиды/кетоны без токсичных солей хрома.
  • Озонолиз алкенов с восстановительным расщеплением:
    $\ce{R1-CH=CH-R2 + O3 -> ... ->[Zn / H2O] R1-CHO + R2-CHO}$

3. Химические свойства

А. Реакции нуклеофильного присоединения ($\text{A}_\text{N}$)

Примечание: Альдегиды более реакционноспособны, чем кетоны, из-за меньшего пространственного затруднения и отсутствия второго электрондонорного алкильного радикала.

  1. Присоединение синильной кислоты ($\ce{HCN}$) — образование циангидринов (оксинитрилов):
    $\ce{R-CHO + HCN ->[OH^-] R-CH(OH)-CN}$
  2. Присоединение гидросульфита натрия ($\ce{NaHSO3}$):
    Качественная реакция на альдегиды и метилкетоны (образуется кристаллический осадок):
    $\ce{R-CHO + NaHSO3 -> R-CH(OH)-SO3Na v}$
  3. Присоединение спиртов (обратимое):
    Образование полуацеталей и ацеталей (в присутствии кислотного катализатора $\ce{H^+}$):
    $\ce{R-CHO + R'OH <=>[\ce{H^+}] R-CH(OH)-OR'}$ (полуацеталь)
    $\ce{R-CH(OH)-OR' + R'OH <=>[\ce{H^+}] R-CH(OR')2 + H2O}$ (ацеталь)
  4. Присоединение реактивов Гриньяра ($\ce{R'MgX}$):
    С формальдегидом $\rightarrow$ первичные спирты:
    $\ce{HCHO + R'MgX -> R'-CH2-OMgX ->[H2O] R'-CH2OH + Mg(OH)X}$
    С другими альдегидами $\rightarrow$ вторичные спирты:
    $\ce{R-CHO + R'MgX -> R-CH(R')-OMgX ->[H2O] R-CH(OH)-R' + Mg(OH)X}$
    С кетонами $\rightarrow$ третичные спирты:
    $\ce{R1-CO-R2 + R'MgX -> R1-C(OH)(R')-R2 + Mg(OH)X}$

Б. Реакции присоединения-отщепления (с N-нуклеофилами)

Взаимодействие с первичными аминами и derivatives аммиакa ($\ce{H2N-Z}$):

  • С первичными аминами ($\ce{R'NH2}$): образование иминов (оснований Шиффа):
    $\ce{R-CHO + R'NH2 -> R-CH=N-R' + H2O}$
  • С гидроксиламином ($\ce{NH2OH}$): образование оксимов:
    $\ce{R-CHO + NH2OH -> R-CH=N-OH + H2O}$
  • С гидразином ($\ce{NH2NH2}$): образование гидразонов:
    $\ce{R-CHO + NH2NH2 -> R-CH=N-NH2 + H2O}$
  • С 2,4-динитрофенилгидразином (2,4-ДНФГ): Качественная реакция — выпадение ярко-желтого или оранжевого осадка 2,4-динитрофенилгидразона.

В. Реакции с участием $\alpha$-водородного атома

  1. Альдольная конденсация:
    Протекает в щелочной среде для соединений, имеющих $\alpha$-водородный атом:
    $\ce{2CH3-CHO ->[NaOH, t^\circ < 20^\circ\text{C}] CH3-CH(OH)-CH2-CHO}$ (3-гидроксибутаналь / альдоль)
  2. Кротоновая конденсация (отщепление воды при нагревании):
    $\ce{CH3-CH(OH)-CH2-CHO ->[\Delta] CH3-CH=CH-CHO + H2O}$ (кротоновый альдегид)
  3. Галогенирование по $\alpha$-положению:
    $\ce{CH3-CO-CH3 + Br2 ->[H^+] CH3-CO-CH2Br + HBr}$
  4. Галоформная (йодоформная) реакция:
    Качественная реакция на ацетальдегид и метилкетоны ($\ce{R-CO-CH3}$):
    $\ce{CH3-CO-R + 3I2 + 4NaOH -> CHI3 v + R-COONa + 3NaI + 3H2O}$
    $\ce{CHI3}$ — желтый осадок йодоформа со специфическим запахом.

Г. Реакции окисления и восстановления

  1. Восстановление:
    До спиртов (реагентами $\ce{NaBH4}$ или $\ce{LiAlH4}$):
    $\ce{R-CHO ->[LiAlH4][H^+] R-CH2OH}$
    $\ce{R1-CO-R2 ->[NaBH4][H^+] R1-CH(OH)-R2}$
    До углеводородов:
    Реакция Клемменсена: $\ce{R-CO-R' ->[Zn(Hg), HCl] R-CH2-R'}$
    Реакция Кижнера — Вольфа: $\ce{R-CO-R' ->[NH2NH2, KOH][\Delta] R-CH2-R' + N2\uparrow}$
  2. Окисление альдегидов (кетоны устойчивы к мягкому окислению):
    $\ce{R-CHO + [O] ->[KMnO4 / K2Cr2O7, H2SO4] R-COOH}$
  3. Реакция Канниццаро (диспропорционирование):
    Протекает для альдегидов, не содержащих $\alpha$-водородных атомов (бензальдегид, формальдегид), в концентрированной щелочи:
    $\ce{2C6H5-CHO + KOH -> C6H5-COOK + C6H5-CH2OH}$
