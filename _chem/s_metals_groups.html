1. Общая характеристика s-металлов

К s-металлам относятся элементы IА (щелочные металлы: $\text{Li}$, $\text{Na}$, $\text{K}$, $\text{Rb}$, $\text{Cs}$, $\text{Fr}$) и IIА групп (щелочноземельные металлы, а также $\text{Be}$ и $\text{Mg}$: $\text{Be}$, $\text{Mg}$, $\text{Ca}$, $\text{Sr}$, $\text{Ba}$, $\text{Ra}$).

  • IА группа (Щелочные металлы): Валентная конфигурация $ns^1$. Степень окисления в соединениях всегда $+1$. Сильнейшие восстановители.
  • IIА группа ($\text{Be}$, $\text{Mg}$ и щелочноземельные металлы): Валентная конфигурация $ns^2$. Степень окисления в соединениях $+2$ (для $\text{Be}$ характерна амфотерность).

2. Химические свойства щелочных металлов (IА группа)

2.1. Взаимодействие с простыми веществами

Горение на воздухе (образование оксидов, пероксидов, надпероксидов):

  • Литий образует оксид: $4\text{Li} + \text{O}_2 \rightarrow 2\text{Li}_2\text{O}$
  • Натрий образует пероксид: $2\text{Na} + \text{O}_2 \rightarrow \text{Na}_2\text{O}_2$
  • Калий, рубидий, цезий образуют надпероксиды (супероксиды): $\text{K} + \text{O}_2 \rightarrow \text{KO}_2$

Реакции с галогенами, серой, водородом, азотом и фосфором:

  • Взаимодействие с галогенами: $2\text{Na} + \text{Cl}_2 \rightarrow 2\text{NaCl}$
  • Взаимодействие с серой (сульфиды): $2\text{K} + \text{S} \rightarrow \text{K}_2\text{S}$
  • Взаимодействие с водородом (гидриды): $2\text{Na} + \text{H}_2 \rightarrow 2\text{NaH}$
  • Взаимодействие с азотом (при комн. темп. только $\text{Li}$): $6\text{Li} + \text{N}_2 \rightarrow 2\text{Li}_3\text{N}$
  • Взаимодействие с фосфором (фосфиды): $3\text{K} + \text{P} \rightarrow \text{K}_3\text{P}$

2.2. Взаимодействие со сложными веществами

  • С водой: $2\text{Na} + 2\text{H}_2\text{O} \rightarrow 2\text{NaOH} + \text{H}_2\uparrow$
  • С кислотами-неокислителями: $2\text{K} + 2\text{HCl} \rightarrow 2\text{KCl} + \text{H}_2\uparrow$
  • С органическими соединениями (спирты, фенолы, кислоты):
    $2\text{C}_2\text{H}_5\text{OH} + 2\text{Na} \rightarrow 2\text{C}_2\text{H}_5\text{ONa} + \text{H}_2\uparrow$

3. Химические свойства элементов IIА группы (Be, Mg, Ca, Sr, Ba)

3.1. Взаимодействие с простыми веществами

  • С кислородом (горение): $2\text{Mg} + \text{O}_2 \rightarrow 2\text{MgO}$ (для $\text{Ba}$ при нагревании возможно образование пероксида: $\text{Ba} + \text{O}_2 \rightarrow \text{BaO}_2$)
  • С галогенами: $\text{Ca} + \text{Cl}_2 \rightarrow \text{CaCl}_2$
  • С водородом (при нагревании): $\text{Ca} + \text{H}_2 \rightarrow \text{CaH}_2$
  • С азотом, углеродом, кремнием:
    $3\text{Mg} + \text{N}_2 \rightarrow \text{Mg}_3\text{N}_2$
    $\text{Ca} + 2\text{C} \rightarrow \text{CaC}_2$
    $2\text{Mg} + \text{Si} \rightarrow \text{Mg}_2\text{Si}$

3.2. Взаимодействие со сложными веществами

  • С водой:
    Бериллий $\text{Be}$ с водой не реагирует.
    Магний $\text{Mg}$ реагирует при кипячении: $\text{Mg} + 2\text{H}_2\text{O} \rightarrow \text{Mg(OH)}_2\downarrow + \text{H}_2\uparrow$ (с перегретым паром: $\text{Mg} + \text{H}_2\text{O} \xrightarrow{t} \text{MgO} + \text{H}_2\uparrow$)
    Щелочноземельные металлы ($\text{Ca}$, $\text{Sr}$, $\text{Ba}$) активны при комн. темп.: $\text{Ca} + 2\text{H}_2\text{O} \rightarrow \text{Ca(OH)}_2 + \text{H}_2\uparrow$
  • Особенность бериллия (амфотерность):
    С растворами щелочей: $\text{Be} + 2\text{NaOH} + 2\text{H}_2\text{O} \rightarrow \text{Na}_2[\text{Be(OH)}_4] + \text{H}_2\uparrow$
    С расплавами щелочей: $\text{Be} + 2\text{NaOH} \xrightarrow{t} \text{Na}_2\text{BeO}_2 + \text{H}_2\uparrow$

4. Важнейшие соединения s-металлов и их свойства

4.1. Гидриды, пероксиды и надпероксиды

  • Гидролиз гидридов: $\text{NaH} + \text{H}_2\text{O} \rightarrow \text{NaOH} + \text{H}_2\uparrow$
  • Реакции пероксидов и надпероксидов с $\text{CO}_2$ (регенерация кислорода):
    $2\text{Na}_2\text{O}_2 + 2\text{CO}_2 \rightarrow 2\text{Na}_2\text{CO}_3 + \text{O}_2\uparrow$
    $4\text{KO}_2 + 2\text{CO}_2 \rightarrow 2\text{K}_2\text{CO}_3 + 3\text{O}_2\uparrow$
  • Реакция пероксида натрия с разбавленной кислотой: $\text{Na}_2\text{O}_2 + \text{H}_2\text{SO}_4 \rightarrow \text{Na}_2\text{SO}_4 + \text{H}_2\text{O}_2$

4.2. Оксиды и гидроксиды

  • Основные оксиды: $\text{Na}_2\text{O} + \text{H}_2\text{O} \rightarrow 2\text{NaOH}$, $\text{CaO} + \text{H}_2\text{O} \rightarrow \text{Ca(OH)}_2$
  • Амфотерный оксид и гидроксид бериллия:
    $\text{BeO} + 2\text{HCl} \rightarrow \text{BeCl}_2 + \text{H}_2\text{O}$
    $\text{BeO} + 2\text{NaOH} + \text{H}_2\text{O} \rightarrow \text{Na}_2[\text{Be(OH)}_4]$
    $\text{Be(OH)}_2 + 2\text{NaOH} \rightarrow \text{Na}_2[\text{Be(OH)}_4]$

4.3. Термическое разложение солей s-металлов

Разложение гидрокарбонатов и карбонатов:

  • $2\text{NaHCO}_3 \xrightarrow{t} \text{Na}_2\text{CO}_3 + \text{CO}_2\uparrow + \text{H}_2\text{O}$
  • $\text{CaCO}_3 \xrightarrow{t} \text{CaO} + \text{CO}_2\uparrow$
  • $\text{Li}_2\text{CO}_3 \xrightarrow{t} \text{Li}_2\text{O} + \text{CO}_2\uparrow$ (карбонаты остальных щелочных металлов устойчивы к нагреванию)

Разложение нитратов:

  • Нитрат лития: $4\text{LiNO}_3 \xrightarrow{t} 2\text{Li}_2\text{O} + 4\text{NO}_2\uparrow + \text{O}_2\uparrow$
  • Нитраты щелочных металлов (от $\text{Na}$ до $\text{Cs}$): $2\text{KNO}_3 \xrightarrow{t} 2\text{KNO}_2 + \text{O}_2\uparrow$
  • Нитраты элементов IIА группы ($\text{Mg}$, $\text{Ca}$, $\text{Ba}$ и др.): $2\text{Ca(NO}_3)_2 \xrightarrow{t} 2\text{CaO} + 4\text{NO}_2\uparrow + \text{O}_2\uparrow$

5. Качественные реакции и свойства растворимости

5.1. Окрашивание пламени катионами s-металлов

Ион Цвет пламени
$\text{Li}^+$Карминово-красный
$\text{Na}^+$Желтый
$\text{K}^+$Фиолетовый (через синее стекло)
$\text{Ca}^{2+}$Кирпично-красный
$\text{Sr}^{2+}$Тёмно-красный / рубиновый
$\text{Ba}^{2+}$Желто-зеленый / яблочно-зеленый

5.2. Качественные реакции в растворах

  • Качественная реакция на катион бария $\text{Ba}^{2+}$: образование белого осадка, нерастворимого в кислотах.
    $\text{Ba}^{2+} + \text{SO}_4^{2-} \rightarrow \text{BaSO}_4\downarrow$
  • Качественная реакция на катион кальция $\text{Ca}^{2+}$: образование белого осадка оксалата.
    $\text{Ca}^{2+} + \text{C}_2\text{O}_4^{2-} \rightarrow \text{CaC}_2\text{O}_4\downarrow$
