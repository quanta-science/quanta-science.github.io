1. Водород \(\text{H}_2\)

1.1. Получение водорода

  • В промышленности:
    • Конверсия метана с водяным паром: $$\text{CH}_4 + \text{H}_2\text{O} \xrightarrow[t, \text{Ni}]{} \text{CO} + 3\text{H}_2$$
    • Газификация угля: $$\text{C} + \text{H}_2\text{O} \xrightarrow{t} \text{CO} + \text{H}_2$$
    • Электролиз воды: $$2\text{H}_2\text{O} \xrightarrow{\text{электролиз}} 2\text{H}_2\uparrow + \text{O}_2\uparrow$$
  • В лаборатории (аппарат Киппа):
    • Взаимодействие цинка с кислотами: $$\text{Zn} + 2\text{HCl} \rightarrow \text{ZnCl}_2 + \text{H}_2\uparrow$$
    • Взаимодействие алюминия со щелочью: $$2\text{Al} + 2\text{NaOH} + 6\text{H}_2\text{O} \rightarrow 2\text{Na}[\text{Al}(\text{OH})_4] + 3\text{H}_2\uparrow$$
    • Гидролиз гидридов: $$\text{CaH}_2 + 2\text{H}_2\text{O} \rightarrow \text{Ca}(\text{OH})_2 + 2\text{H}_2\uparrow$$

1.2. Химические свойства водорода

  • Восстановительные свойства (с неметаллами):
    • С кислородом: $$2\text{H}_2 + \text{O}_2 \xrightarrow{t} 2\text{H}_2\text{O}$$
    • С азотом: $$N_2 + 3\text{H}_2 \rightleftharpoons {p, t, \text{Fe}} 2\text{NH}_3$$
    • С серой: $$\text{H}_2 + \text{S} \xrightarrow{t} \text{H}_2\text{S}$$
    • С галогенами: $$\text{H}_2 + \text{Cl}_2 \xrightarrow{h\nu} 2\text{HCl}$$
  • Восстановление металлов из оксидов:
    • $$\text{CuO} + \text{H}_2 \xrightarrow{t} \text{Cu} + \text{H}_2\text{O}$$
    • $$\text{Fe}_3\text{O}_4 + 4\text{H}_2 \xrightarrow{t} 3\text{Fe} + 4\text{H}_2\text{O}$$
  • Окислительные свойства (с активными металлами):
    • $$2\text{Na} + \text{H}_2 \xrightarrow{t} 2\text{NaH}$$
    • $$\text{Ca} + \text{H}_2 \xrightarrow{t} \text{CaH}_2$$

2. Вода \(\text{H}_2\text{O}\)

2.1. Физико-химические постоянные и свойства

  • Молярная масса: $$M(\text{H}_2\text{O}) = 18{,}015 \text{ г/моль}$$
  • Ионное произведение воды при 25 °C: $$K_w = [\text{H}^+][\text{OH}^-] = 10^{-14} \text{ моль}^2/\text{л}^2$$
  • Водородный показатель: $$\text{pH} = -\lg[\text{H}^+] = 7 \text{ (нейтральная среда)}$$

2.2. Основные химические реакции

  • С активными металлами: $$2\text{Na} + 2\text{H}_2\text{O} \rightarrow 2\text{NaOH} + \text{H}_2\uparrow$$
  • С основным оксидами: $$\text{CaO} + \text{H}_2\text{O} \rightarrow \text{Ca}(\text{OH})_2$$
  • С кислотными оксидами: $$\text{P}_2\text{O}_5 + 3\text{H}_2\text{O} \xrightarrow{t} 2\text{H}_3\text{PO}_4$$
  • Гидролиз солей (пример): $$\text{Na}_2\text{CO}_3 + \text{H}_2\text{O} \rightleftharpoons \text{NaHCO}_3 + \text{NaOH}$$

3. Пероксид водорода \(\text{H}_2\text{O}_2\)

3.1. Способы получения

  • Лабораторный метод (действие кислот на пероксиды):
    $$\text{BaO}_2 + \text{H}_2\text{SO}_4 \rightarrow \text{BaSO}_4\downarrow + \text{H}_2\text{O}_2$$

3.2. Разложение пероксида водорода

  • Каталитическое/термическое диспропорционирование:
    $$2\text{H}_2\text{O}_2 \xrightarrow{\text{MnO}_2 \text{ или } t} 2\text{H}_2\text{O} + \text{O}_2\uparrow$$

3.3. Окислительно-восстановительная двойственность

Степень окисления кислорода в \(\text{H}_2\text{O}_2\) равна -1.

  • Как окислитель (восстанавливается до \(\text{H}_2\text{O}\) или \(\text{OH}^-\):
    • В кислой среде: $$\text{H}_2\text{O}_2 + 2\text{KI} + \text{H}_2\text{SO}_4 \rightarrow \text{I}_2 + \text{K}_2\text{SO}_4 + 2\text{H}_2\text{O}$$
    • Окисление сульфидов до сульфатов: $$\text{PbS} + 4\text{H}_2\text{O}_2 \rightarrow \text{PbSO}_4 + 4\text{H}_2\text{O}$$
    • Взаимодействие с солями железа(II): $$2\text{FeSO}_4 + \text{H}_2\text{O}_2 + \text{H}_2\text{SO}_4 \rightarrow \text{Fe}_2(\text{SO}_4)_3 + 2\text{H}_2\text{O}$$
  • Как восстановитель (окисляется до \(\text{O}_2\)):
    • С сильными окислителями (KMnO₄ в кислой среде):
      $$2\text{KMnO}_4 + 5\text{H}_2\text{O}_2 + 3\text{H}_2\text{SO}_4 \rightarrow 2\text{MnSO}_4 + \text{K}_2\text{SO}_4 + 5\text{O}_2\uparrow + 8\text{H}_2\text{O}$$
    • С оксидом серебра:
      $$\text{Ag}_2\text{O} + \text{H}_2\text{O}_2 \rightarrow 2\text{Ag} + \text{O}_2\uparrow + \text{H}_2\text{O}$$
    • С хлором:
      $$\text{Cl}_2 + \text{H}_2\text{O}_2 \rightarrow 2\text{HCl} + \text{O}_2\uparrow$$
