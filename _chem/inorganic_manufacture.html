1. Синтез аммиака (Процесс Габера — Боша)

Суть процесса: Каталитический синтез из азота и водорода при высоком давлении и температуре.

Основное уравнение реакции:

$$\text{N}_2\text{(г)} + 3\text{H}_2\text{(г)} \rightleftharpoons 2\text{NH}_3\text{(г)} \quad \Delta H^\circ = -92.4\text{ кДж/моль}$$

Условия и параметры процесса

  • Катализатор: Пористое железо с промоторами ($\text{Al}_2\text{O}_3, \text{K}_2\text{O}, \text{CaO}, \text{SiO}_2$). В современных технологиях (процесс Kellogg Advanced Ammonia Process, KAAP) используется катализатор на основе рутения ($\text{Ru}$) на углеродном носителе.
  • Давление: $15 \text{ — } 30 \text{ МПа}$ ($150 \text{ — } 300 \text{ атм}$).
  • Температура: $400 \text{ — } 500 \text{ ^\circ C}$ (компромисс между скоростью реакции и смещением равновесия по принципу Ле Шателье).
  • Выход: $15 \text{ — } 20\%$ за один проход; нереагировавшая смесь возвращается в циркуляцию после конденсации $\text{NH}_3$.

Современные тенденции (Зелёный аммиак)

Электролиз воды с использованием возобновляемых источников энергии (ВИЭ) для получения $\text{H}_2$ и криогенное разделение воздуха для $\text{N}_2$, что исключает выбросы $\text{CO}_2$.

2. Производство серной кислоты (Контактный метод)

Сырьё: Сера ($\text{S}$), пирит ($\text{FeS}_2$), сероводород ($\text{H}_2\text{S}$).

Стадия 1: Получение диоксида серы ($\text{SO}_2$)

Сжигание серы:

$$\text{S} + \text{O}_2 \rightarrow \text{SO}_2 \quad \Delta H^\circ = -297\text{ кДж/моль}$$

Обжиг пирита в кипящем слое:

$$4\text{FeS}_2 + 11\text{O}_2 \rightarrow 2\text{Fe}_2\text{O}_3 + 8\text{SO}_2 \quad \Delta H^\circ = -3308\text{ кДж/моль}$$

Стадия 2: Каталитическое окисление $\text{SO}_2$ в $\text{SO}_3$

$$\text{SO}_2 + \frac{1}{2}\text{O}_2 \rightleftharpoons \text{SO}_3 \quad \Delta H^\circ = -99\text{ кДж/моль}$$

  • Катализатор: Оксид ванадия(V) $\text{V}_2\text{O}_5$ с добавками солей калия (активен при $400 \text{ — } 600 \text{ ^\circ C}$). В современных установках внедряются цезий-промотированные ванадиевые катализаторы, работающие при более низких температурах ($390 \text{ ^\circ C}$), что повышает степень конверсии.
  • Технология ДКДА (Двойное контактирование — двойная абсорбция): Позволяет достичь конверсии $\text{SO}_2 \ge 99.85\%$.

Стадия 3: Абсорбция трёхокиси серы

Поглощение $\text{SO}_3$ ведущим $98.3\%$-ным раствором $\text{H}_2\text{SO}_4$ с образованием олеума ($\text{H}_2\text{S}_2\text{O}_7$):

$$\text{SO}_3 + \text{H}_2\text{SO}_4 \rightarrow \text{H}_2\text{S}_2\text{O}_7$$

$$\text{H}_2\text{S}_2\text{O}_7 + \text{H}_2\text{O} \rightarrow 2\text{H}_2\text{SO}_4$$

Примечание: Растворение напрямую в воде не применяется из-за образования устойчивого тумана $\text{H}_2\text{SO}_4$.

3. Производство азотной кислоты (Метод Оствальда)

Сырьё: Аммиак ($\text{NH}_3$), воздух, вода.

Стадия 1: Каталитическое окисление аммиака до $\text{NO}$

$$4\text{NH}_3 + 5\text{O}_2 \xrightarrow{\text{Pt-Rh}} 4\text{NO} + 6\text{H}_2\text{O} \quad \Delta H^\circ = -906\text{ кДж/моль}$$

  • Условия: $850 \text{ — } 920 \text{ ^\circ C}$, время контакта $< 0.001\text{ с}$.
  • Катализатор: Сетка из сплава платины ($\sim 90\%$), родия ($\sim 5\%$) и палладия ($\sim 5\%$).

Стадия 2: Окисление $\text{NO}$ до $\text{NO}_2$

Охлаждение газовой смеси приводит к гомогенному окислению:

$$2\text{NO} + \text{O}_2 \rightleftharpoons 2\text{NO}_2 \quad \Delta H^\circ = -114\text{ кДж/моль}$$

Параллельно происходит димеризация:

$$2\text{NO}_2 \rightleftharpoons \text{N}_2\text{O}_4$$

Стадия 3: Абсорбция диоксида азота водой

$$3\text{NO}_2 + \text{H}_2\text{O} \rightarrow 2\text{HNO}_3 + \text{NO}$$

В присутствии избытка кислорода (под давлением до $1 \text{ МПа}$):

$$4\text{NO}_2 + \text{O}_2 + 2\text{H}_2\text{O} \rightarrow 4\text{HNO}_3$$

Концентрирование: Для получения разбавленной кислоты ($\sim 65\%$) используется обычная абсорбция. Разбавленная кислота концентрируется экстрактивной ректификацией с $\text{Mg(NO}_3\text{)}_2$ или $\text{H}_2\text{SO}_4$.

4. Хлор-щелочное производство (Хлор и NaOH)

Сырьё: Водный раствор хлорида натрия ($\text{NaCl}$).

Суммарная реакция электролиза:

$$2\text{NaCl} + 2\text{H}_2\text{O} \xrightarrow{\text{электролиз}} \text{Cl}_2\uparrow + \text{H}_2\uparrow + 2\text{NaOH}$$

5. Промышленное производство водорода

1. Паровая конверсия метана (SMR — Steam Methane Reforming)

Основной мировой способ (серый водород):

$$\text{CH}_4 + \text{H}_2\text{O}\text{(пар)} \xrightarrow{\text{Ni}, 700-1000^\circ\text{C}} \text{CO} + 3\text{H}_2 \quad \Delta H^\circ = +206\text{ кДж/моль}$$

Парофазная конверсия оксида углерода(II) (Water-Gas Shift reaction):

$$\text{CO} + \text{H}_2\text{O}\text{(пар)} \xrightarrow{\text{Fe}_3\text{O}_4 / \text{Cu}} \text{CO}_2 + \text{H}_2 \quad \Delta H^\circ = -41\text{ кДж/моль}$$

2. Автотермический реформинг (ATR) и Парциальное окисление (POX)

Окисление углеводородов с нехваткой кислорода:

$$\text{CH}_4 + \frac{1}{2}\text{O}_2 \rightarrow \text{CO} + 2\text{H}_2 \quad \Delta H^\circ = -36\text{ кДж/моль}$$

3. Газификация угля

$$\text{C} + \text{H}_2\text{O} \xrightarrow{1000^\circ\text{C}} \text{CO} + \text{H}_2$$

4. Электролиз воды (Зелёный водород)

Окислительно-восстановительная реакция:

$$2\text{H}_2\text{O}\text{(ж)} \xrightarrow{\text{эл. ток}} 2\text{H}_2\uparrow + \text{O}_2\uparrow$$

Технологии: Щелочной электролиз (AEL), протонно-обменные мембраны (PEMEL), твердооксидный электролиз при высоких температурах (SOEC).

5. Пиролиз метана (Бирюзовый водород)

Термический распад без доступа воздуха без образования $\text{CO}_2$:

$$\text{CH}_4 \xrightarrow{T > 800^\circ\text{C}} \text{C}\text{(тв)} + 2\text{H}_2\text{(г)}$$

6. Металлургия (Получение важнейших металлов)

Черная металлургия: Доменный процесс и ПВЖ (Direct Reduced Iron)

Восстановление в доменной печи:

$$3\text{Fe}_2\text{O}_3 + \text{CO} \xrightarrow{400-500^\circ\text{C}} 2\text{Fe}_3\text{O}_4 + \text{CO}_2$$

$$\text{Fe}_3\text{O}_4 + \text{CO} \xrightarrow{500-700^\circ\text{C}} 3\text{FeO} + \text{CO}_2$$

$$\text{FeO} + \text{CO} \xrightarrow{700-900^\circ\text{C}} \text{Fe} + \text{CO}_2$$

Прямое восстановление железа (MIDREX — современный бескоксовый метод):

$$\text{Fe}_2\text{O}_3 + 3\text{H}_2 \rightarrow 2\text{Fe} + 3\text{H}_2\text{O}$$

Производство алюминия (Процесс Холла — Эру)

Электролиз раствора глинозёма ($\text{Al}_2\text{O}_3$) в расплаве криолита ($\text{Na}_3\text{AlF}_6$) при $950\text{ ^\circ C}$ с угольным анодом:

Катод (графит): $$\text{Al}^{3+} + 3e^- \rightarrow \text{Al}\text{(ж)}$$

Анод (угольные блоки): $$2\text{O}^{2-} - 4e^- \rightarrow \text{O}_2$$

Суммарно с выгоранием анода:

$$2\text{Al}_2\text{O}_3 + 3\text{C} \rightarrow 4\text{Al} + 3\text{CO}_2\uparrow$$

Современные разработки: Инертные аноды ($\text{Fe-Ni-Cu}$ керамика), выделяющие чистый кислород $\text{O}_2$ вместо $\text{CO}_2$.

Производство титана (Процесс Кролла)

1. Хлорирование руды (рутила $\text{TiO}_2$):

$$\text{TiO}_2 + 2\text{Cl}_2 + 2\text{C} \xrightarrow{900^\circ\text{C}} \text{TiCl}_4 + 2\text{CO}$$

2. Магниетермическое восстановление в атмосфере аргона:

$$\text{TiCl}_4 + 2\text{Mg} \xrightarrow{800-850^\circ\text{C}} \text{Ti}\text{(губка)} + 2\text{MgCl}_2$$

7. Производство фосфорной кислоты

Экстракционный (сернокислотный) метод

Разложение апатита $\text{Ca}_5(\text{PO}_4)_3\text{F}$:

$$\text{Ca}_5(\text{PO}_4)_3\text{F} + 5\text{H}_2\text{SO}_4 + 10\text{H}_2\text{O} \rightarrow 3\text{H}_3\text{PO}_4 + 5(\text{CaSO}_4 \cdot 2\text{H}_2\text{O})\downarrow + \text{HF}\uparrow$$

Термический метод (Высокочистая кислота)

1. Восстановление фосфорита в электропечах:

$$2\text{Ca}_3(\text{PO}_4)_2 + 6\text{SiO}_2 + 10\text{C} \xrightarrow{1500^\circ\text{C}} P_4 + 6\text{CaSiO}_3 + 10\text{CO}$$

2. Сжигание и гидратация:

$$\text{P}_4 + 5\text{O}_2 \rightarrow \text{P}_4\text{O}_{10}$$

$$\text{P}_4\text{O}_{10} + 6\text{H}_2\text{O} \rightarrow 4\text{H}_3\text{PO}_4$$
